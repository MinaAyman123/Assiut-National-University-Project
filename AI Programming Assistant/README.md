# 🤖 AI Programming Assistant

An AI-powered platform for learning programming languages with leveled lessons, auto-generated quizzes, and smart code explanation.

---

## ✨ Features

- 🤖 **AI-Powered Learning** — Lessons explained by LLM (Ollama)
- 📚 **Leveled Curriculum** — 15 progressive levels per language
- 📝 **Auto-Generated Quizzes** — 10 questions per level, generated from the lesson content
- 🔍 **Smart Code Explainer** — Analyzes code, explains it line-by-line, and fixes errors
- 👤 **User Authentication** — Register and login system
- 📊 **Progress Tracking** — User progress saved per language in the database
- 🌍 **Full Arabic Support** — RTL interface with Arabic explanations

## 🚀 Getting Started

### Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download)
- [SQL Server](https://www.microsoft.com/en-us/sql-server/sql-server-downloads)
- [Ollama](https://ollama.com/download)

### 1. Install Ollama models

```bash
ollama pull llama3.2:3b
ollama pull qwen2.5-coder:3b
```

Make sure Ollama is running:

```bash
ollama serve
```

### 2. Setup the database

Create a database named `ai_programming_assistant` with these tables:

- `users`
- `programming_language`
- `users_programming_language`
- `learning_content`

Or update the connection string in `appsettings.json`:

```json
"ConnectionStrings": {
  "DefaultConnection": "Server=YOUR_SERVER;Database=ai_programming_assistant;Trusted_Connection=True;TrustServerCertificate=True"
}
```

### 3. Run the project

```bash
dotnet restore
dotnet build
dotnet run
```

Open your browser at:

```
https://localhost:5001
```

## 🎯 How It Works

1. **User picks a language** (C#, Python, JavaScript, ...)
2. **If content exists in DB** → loaded directly
3. **If not** → generated by Ollama and saved for future use
4. **After each level** → a 10-question quiz is generated from the lesson content
5. **Passing score** → 70% unlocks the next level
6. **Progress saved** in `users_programming_language` table

## 🧪 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/Learning/Learning` | Learning page |
| POST | `/Learning/GetContent` | Get lesson content |
| POST | `/Learning/GenerateQuiz` | Generate quiz for current level |
| POST | `/Learning/UpdateProgress` | Update user level |
| POST | `/Learning/GetUserCourses` | Get user's started courses |
| POST | `/Code_Explainer/getcurrentExplanation_currentFixedCode` | Analyze code |
| POST | `/login_create_account/login_create_account` | Login |
| POST | `/login_create_account/Register` | Register |
